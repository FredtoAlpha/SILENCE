# Déposer un feuilleton

1. Télécharge `_MODELE.docx` (ou `public/modele-feuilleton.docx`).
2. Remplis la fiche en tête : **Titre, Niveau, Matière, Accroche**.
3. Écris les épisodes. Ne change pas les styles **Titre 1** et **Titre 2**.
4. Enregistre sous le nom du livre, par exemple `Le sel de la mer.docx`.
5. Dépose-le ici, dans le dossier de la classe et de la matière :

```
inbox/4e/histoire/
inbox/4e/geographie/
inbox/4e/emc/
inbox/4e/francais/
inbox/3e/histoire/
inbox/3e/geographie/
inbox/3e/emc/
inbox/3e/francais/
```

Couverture facultative : la même image, même nom, à côté du Word (`Le sel de la mer.jpg`).

GitHub s’occupe du reste. Quelques minutes plus tard, le livre est sur l’étagère.
